# Quote of the Day (Chrome Extension)

A simple Manifest V3 Chrome extension that shows a random motivational quote when you open the popup. Click the button to generate a new quote.

## Files
- `manifest.json`: Extension manifest (MV3).
- `popup.html`: Popup UI.
- `popup.js`: Popup logic for picking quotes.
- `quotes.js`: Local quote list.

## Load in Chrome
1. Open `chrome://extensions/`.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this folder (`quote-of-the-day`).

## Customize
Add or edit quotes in `quotes.js`.
